
# Cyber Prank Control 2.0

Интерактивный конструктор вымышленных кибер-сценариев.

## Установка

1. Открой GitHub.
2. Открой репозиторий Cyber-Prank-Control.
3. Создай или замени index.html.
4. Вставь код из проекта.
5. Нажми Commit changes.
6. Перейди в Settings → Pages.
7. Выбери Deploy from a branch.
8. Выбери ветку main и папку /(root).
9. Нажми Save.

## Возможности

- Адаптивный интерфейс для компьютеров и телефонов.
- Генератор персональных ссылок.
- Настраиваемые названия и сообщения.
- Предпросмотр сценария.
- Neon Pink, Cyber Red, Black & Cyan, Purple Glitch.
- Glitch-анимация.
- Движущиеся линии сканера.
- Псевдотерминал.
- Анимация входящего сообщения.
- Анимация письма.
- Локальный список ссылок.
- Кнопка закрытия сценария.

## Хранение

Сценарий кодируется непосредственно в URL.
История созданных ссылок хранится в localStorage браузера.

## Ограничения

Это статический сайт на GitHub Pages.

Удаление ссылки из локального списка не отключает уже скопированную ссылку.

Для удалённого отключения сценариев, общей панели управления,
аккаунтов и серверной статистики необходимо подключить backend.

Сайт не сканирует устройства и не получает доступ к личным файлам.
Все эффекты являются постановочной анимацией.
